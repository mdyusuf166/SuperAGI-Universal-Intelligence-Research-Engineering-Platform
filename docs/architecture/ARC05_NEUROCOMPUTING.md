# ARC-05 Neurocomputing

ARC-05 supplies typed neuron, network, spike, simulation, and brain-region abstractions. Brian2 and NEST are optional adapter boundaries; unavailable adapters return structured status rather than synthetic simulations. The mock backend is explicitly deterministic and intended only for tests/demos. All measures are simplified computational neuroscience measurements, not evidence of cognition, consciousness, disease, human brain replication, BCI capability, or clinical effect.
